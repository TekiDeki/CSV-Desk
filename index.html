CSV-Desk

Edit, filter and clean CSV or TSV files without sending them anywhere. Your data stays in this browser.

A small, honest CSV workspace

  • Open a CSV, TSV or TXT file up to 8 MiB, encoded as UTF-8 or UTF-16 with BOM. The original file is never changed.
  • Edit cells, reorder columns, trim whitespace, remove empty or duplicate rows and use literal find and replace.
  • Export the current data as CSV, TSV or JSON. Values stay text and spreadsheet formulas are never executed.

Open your data

Nothing is uploaded. Headerless files can be converted after opening. Unclosed quoted fields are reported instead of being silently truncated.

Columns: rename, reorder, hide or delete

Hidden columns stay in the data and are included in a full export. A filtered-view export includes only visible columns.

Clean and transform

Every operation can be undone. Duplicate removal is exact, case-sensitive and keeps the first complete row.

Export CSV, TSV or JSON

A full export keeps every row and column. A view export applies search, sorting and visible columns. JSON uses unique header keys and keeps every value as text.

Local sessions

Sessions are saved only when you ask, stay in localStorage and never leave this browser. Keep the three most recent small sessions, or export larger files instead.
